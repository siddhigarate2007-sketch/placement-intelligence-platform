### Domain-Engineered Feature Formulations
1. **Academic Consistency Index ($ACI$):**
   $$ACI = \frac{\frac{\text{10th \%}}{10} + \frac{\text{12th \%}}{10} + \text{CGPA}}{3.0}$$
2. **Skill Composite Index ($SCI$):**
   $$SCI = (\text{Coding} \times 0.35) + (\text{Technical} \times 0.30) + (\text{Aptitude} \times 0.20) + (\text{Communication} \times 0.15)$$
3. **Practical Experience Index ($PEI$):**
   $$PEI = (\text{Internships} \times 2.0) + (\text{Projects} \times 1.0) + (\text{Certifications} \times 0.5)$$
